# Color-OS-16-RotFall

> LSPosed 模块：试图修复 ColorOS 16（C16 / OPPO）上**横屏应用退出回桌面时的旋转回落过渡动画**。

模块 ID：`com.rotfix.probe`
作者：wisely-leo

---

## ⚠️ 重要声明（请先读）

这是一个**实验性质、且尚未完成**的模块。请务必了解以下事实：

1. **功能不完善。** 模块的旋转/回落矩阵动画在日志中能看到数值在连续变化，但**横竖屏判定（什么时候该转）一直没有做到可靠**。
2. **代码混乱。** 这是作者在长时间反复试错中堆积出来的产物，经历过大量版本迭代（本仓库源码对应 `v65`）。很多逻辑是"补丁摞补丁"，**可读性和结构都很差**。
3. **横竖屏判断稀烂。** 判定逻辑是在多个错误方向上反复尝试后的残留：早期依赖 `Display` 尺寸、后来试过缩略图旋转、再后来试图反查 `ActivityInfo` 等，**没有一个是真正验证过稳定可用的**。相关代码请见 `isLandscape(...)` 与 `applyOne(...)`。
4. **仅初步验证。** Release APK 在目标机型（C16 / ColorOS）上**已验证可正常加载并运行**，但**未做过系统性回归测试**，旋转效果是否长期稳定、是否适用于其他机型均不确定。**不保证长期可用、不保证不崩、不保证适用于其他机型。**

如果你只是想找"能用的成品"，这大概率不是你要的东西。

### 关于 `src/`

- 来源：`RotFixProbe v65` APK，使用 jadx（开启 inconsistent code 显示）反编译后**去除注释**整理，**全部方法均已还原**（无 `not decompiled` 占位）。
- 仍**不能直接编译**：缺少原有工程结构与依赖（libxposed API 等），仅供阅读参考。
- 日志开关已处理为"**保留完整实现、但运行时立即返回**"（`log(...)` 方法开头 `return`），因此运行时不产生日志输出。
